# CLOSET — Cosplay Rental Marketplace MVP

ต้นแบบเว็บเช่าชุดคอสเพลย์แบบ Frontend-only พร้อมห้องลอง 3D ที่หมุนรอบได้ ผู้ใช้เลือกหุ่นชายหรือหญิง ปรับส่วนสูง อก เอว สะโพก และไหล่ แล้วผสมเสื้อ กางเกง วิก และเครื่องประดับจากคนละร้านได้ในหน้าเดียว

ข้อมูล Cosplay และ Rental Booking เก็บใน IndexedDB ด้วยคีย์ `cosplay-v1` แยกจากข้อมูล Closet รุ่นก่อน จึงไม่ลบหรือแปลงประวัติการซื้อเดิม แค็ตตาล็อกมีภาพถ่ายจริง 15 ภาพพร้อมผู้สร้าง แหล่งต้นฉบับ และสัญญาอนุญาต ส่วนโมเดลเสื้อผ้า 3D เป็นการสร้างรูปทรงโดยประมาณจากภาพอ้างอิง ไม่ใช่การสแกนสินค้า

## เปิดเดโม

ต้องใช้ Node.js 20 ขึ้นไป และเปิดผ่าน local server เพราะหน้าเว็บใช้ ES modules:

```bash
npm start
```

จากนั้นเปิด [http://127.0.0.1:4173](http://127.0.0.1:4173)

## เส้นทางเดโมแนะนำ

1. หน้า **3D Studio** เลือกหุ่นหญิงหรือชาย แล้วลากเพื่อหมุน 360° หรือใช้ปุ่ม หน้า/ซ้าย/หลัง/ขวา
2. กรองธีม Academy, Fantasy หรือ Gothic แล้วเลือกเสื้อ กางเกง วิก และเครื่องประดับทีละชิ้น
3. เปลี่ยนไซซ์เสื้อผ้า และปรับตำแหน่ง การหมุน หรือขนาดของชิ้นที่เลือก โดยหุ่นยังคงอยู่ด้านซ้าย
4. เปิด **สัดส่วนหุ่นของฉัน** เพื่อปรับค่าและบันทึกแยกตามบัญชี ผลประเมิน fit ใช้ข้อมูลขนาด ไม่ใช้ภาพเป็นคำรับรอง
5. เปิดรายละเอียดชิ้นที่สนใจ กด **เช่าชิ้นนี้** เลือกไซซ์ วันรับ และวันคืน แล้วส่งคำขอ
6. เปิด **My Closet → My Rentals** เพื่อดูสถานะ **รอยืนยัน**
7. สลับไปบัญชีผู้ให้เช่า เปิด **Rental Requests** แล้วกด **ยืนยันการเช่า**
8. สลับกลับบัญชีผู้เช่า สถานะใน **My Rentals** จะเป็น **ยืนยันแล้ว**
9. กด **ลงชุดให้เช่า** เพื่อทดลองฟอร์ม 4 ขั้น: ข้อมูลชุด, ไซซ์และขนาด, รูปและพรีวิว, ราคาเช่าต่อวันและเผยแพร่
10. เปิด Flora Sylven หรือ Mika Hanami เพื่อดูภาพ **Flaw / Defect** และเครื่องมือซูม/เลื่อนภาพต้นฉบับ

## พฤติกรรมสำคัญ

- หนึ่งประกาศมีหลายไซซ์ แต่ละไซซ์มีราคาเช่าต่อวัน ขนาดวัด และสถานะเปิดให้เช่าแยกกัน
- จำนวนวันเช่านับรวมวันรับและวันคืน เช่น 11–13 กันยายนเท่ากับ 3 วัน
- คำขอเช่าเก็บชุด ผู้เช่า ผู้ให้เช่า ไซซ์ วันรับ วันคืน ราคาต่อวัน ราคารวม snapshot และสถานะใน `state.rentals`
- คำขอเริ่มที่ `pending` และเปลี่ยนเป็น `confirmed` ได้โดยผู้ให้เช่าเท่านั้น ช่วงวันที่ยืนยันแล้วจะกันคำขอที่ทับซ้อนของชุดและไซซ์เดียวกัน
- การสร้างและยืนยัน Booking ใช้ IndexedDB transaction เดิม และไม่ตัดสต็อกถาวร
- หุ่นใช้ฐาน Human Base Meshes ของ Blender และแสดงผลด้วย Three.js ที่รวมไว้ใน repository จึงไม่พึ่ง CDN
- Fit Summary ใช้กฎจากขนาดวัด แสดง Tight, Good, Slightly Loose, Loose, Short, Long หรือยังประเมินไม่ได้
- สัดส่วนหุ่นชายและหญิงบันทึกแยกกัน ขนาดเสื้อผ้าและการเลื่อนตำแหน่งเป็นข้อมูลคนละส่วนกับสัดส่วนหุ่น
- แต่ละตำแหน่งใส่ได้หนึ่งชิ้น: เสื้อ กางเกง วิก คอ เอว ใบหน้า และผม การเลือกชิ้นใหม่แทนที่เฉพาะตำแหน่งเดียวกัน
- ชุดที่ไม่มี PNG โปร่งใสยังลงให้เช่าได้ โดยแสดงภาพต้นฉบับคู่หุ่นแทน
- ผู้ขายต้องระบุรูปตำหนิและคำอธิบายเมื่อเลือกสภาพ “มีตำหนิ”

## ทดสอบ

```bash
npm test
node --check app.js
node --check cosplay-domain.js
node --check cosplay-seller.js
node --check mannequin.js
node --check studio-renderer.js
node --check studio-ui.js
```

ชุดทดสอบอัตโนมัติครอบคลุมขอบเขต fit การตรวจสัดส่วน สิทธิ์บัญชี การคิดวันเช่าแบบ inclusive การกันวันชน การเก็บ snapshot การยืนยันโดยผู้ให้เช่า การลงชุดให้เช่า และการคงข้อมูลเดิม

## ข้อจำกัดของ MVP

- ไม่มี backend, การชำระเงินจริง, ขนส่ง, tracking, chat, review, ยืนยันตัวตน หรือแจ้งเตือนภายนอก
- ข้อมูลอยู่ในเบราว์เซอร์และเครื่องเดียว อาจหายเมื่อล้างข้อมูลเว็บไซต์
- Virtual preview เป็นโมเดล 3D ที่สร้างโดยประมาณจากภาพอ้างอิง ไม่ใช่ photogrammetry, cloth simulation หรือการรับประกันความพอดี
- ภาพทั้ง 15 ภาพเป็นตัวอย่างจาก Wikimedia Commons และไม่ใช่ stock ของผู้ขายจริง ข้อจำกัดของภาพแต่ละใบอยู่ในเครดิตบนหน้ารายละเอียด
- ผู้ขายต้องเตรียม PNG โปร่งใสเอง ระบบไม่ตัดพื้นหลังและไม่วิเคราะห์รูปด้วย AI
- ผู้ช่วยคำบรรยายและราคาใช้กฎกับข้อมูลในระบบ และเปิดเผยจำนวนรายการเทียบเคียง
