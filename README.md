# TooSuePha — Rental Marketplace MVP

ต้นแบบเว็บเช่าเสื้อผ้าหลายโอกาสแบบ Frontend-only ครอบคลุม Costume, Travel, Outdoor, Formal และ Event พร้อมห้องลอง 3D ที่หมุนรอบได้ ผู้ใช้เลือกหุ่นชายหรือหญิง ปรับส่วนสูง อก เอว สะโพก และไหล่ แล้วผสมเสื้อ กางเกง วิก และเครื่องประดับจากคนละร้านได้ในหน้าเดียว

ข้อมูล Rental Booking เก็บใน IndexedDB ด้วยคีย์เวอร์ชันเดิมเพื่อรักษาประวัติผู้ใช้ แยกจากข้อมูล Closet รุ่นก่อน แค็ตตาล็อกมีภาพถ่ายจริง 15 ภาพพร้อมผู้สร้าง แหล่งต้นฉบับ และสัญญาอนุญาต ส่วนโมเดลเสื้อผ้า 3D เป็นการสร้างรูปทรงโดยประมาณจากภาพอ้างอิง ไม่ใช่การสแกนสินค้า

## เปิดเดโม

ต้องใช้ Node.js 20 ขึ้นไป และเปิดผ่าน local server เพราะหน้าเว็บใช้ ES modules:

```bash
npm start
```

จากนั้นเปิด [http://127.0.0.1:4173](http://127.0.0.1:4173)

## เส้นทางเดโมแนะนำ

1. หน้า **3D Studio** เลือกหุ่นหญิงหรือชาย แล้วลากเพื่อหมุน 360° หรือใช้ปุ่ม หน้า/ซ้าย/หลัง/ขวา
2. กรองธีม Academy, Fantasy หรือ Gothic แล้วเลือกเสื้อ กางเกง วิก และเครื่องประดับทีละชิ้น
3. เปลี่ยนไซซ์เสื้อผ้า และปรับตำแหน่ง การหมุน หรือขนาดของชิ้นที่เลือก โดยหุ่นยังคงอยู่ด้านซ้าย
4. เปิด **สัดส่วนหุ่นของฉัน** เพื่อปรับค่าและบันทึกแยกตามบัญชี ผลประเมิน fit ใช้ข้อมูลขนาด ไม่ใช้ภาพเป็นคำรับรอง
5. เปิดรายละเอียดชิ้นที่สนใจ เลือกไซซ์และวันรับ–คืน จากนั้นเพิ่มหลายชิ้นจากหลายร้านในรายการเช่า
6. กดชำระจำลอง ระบบตรวจวันว่างทั้งรายการแล้วสร้าง Checkout Group, Booking แยกร้าน, Mock Payment และ Escrow ในครั้งเดียว
7. เปิด **My Rentals** เพื่อติดตามช่วงรับชุด: ร้านเตรียม → ร้านส่ง → กำลังจัดส่ง → ผู้เช่าได้รับชุด
8. ติดตามช่วงคืนชุดต่อใน Booking เดิม: กำลังเช่า → เตรียมคืน → ผู้เช่าส่งคืน → ร้านได้รับคืน → ตรวจสภาพ → ทำความสะอาด → เสร็จสิ้น
9. ผู้ให้เช่าจัดการแต่ละ Booking ใน **My Closet → Rental Requests** และเห็น Pending/Available Earnings จาก Mock Escrow
10. กด **ลงชุดให้เช่า** เพื่อทดลองฟอร์ม 4 ขั้น: ข้อมูลชุด, ไซซ์และขนาด, รูปและพรีวิว, ราคาเช่าต่อวันและเผยแพร่
11. เปิด Flora Sylven หรือ Mika Hanami เพื่อดูภาพ **Flaw / Defect** และเครื่องมือซูม/เลื่อนภาพต้นฉบับ

## พฤติกรรมสำคัญ

- Navigation แยกกิจกรรมชัดเจน: Marketplace สำหรับหาชุด, My Rentals สำหรับติดตามชุดที่เช่า และ My Closet สำหรับจัดการชุดที่ปล่อยเช่า
- My Rentals แยก Booking ที่กำลังใช้งานออกจากประวัติ แต่ละรายการแสดงวันรับ–คืน ยอดรวม สถานะ และ Next Action พร้อมหน้า Booking Detail ที่รวม Timeline รับชุดและคืนชุดไว้หน้าเดียว
- Booking Detail แสดง Tracking สองขา, Mock Payment/Escrow และ Fit Match จากสัดส่วนปัจจุบันกับขนาด snapshot โดยไม่แก้หลักฐานตอนจอง
- บัญชีเดียวใช้ได้ทั้งผู้เช่าและผู้ให้เช่า โดย My Closet มีเฉพาะ My Listings และ Rental Requests
- My Listings แสดงสถานะประกาศและไซซ์ที่พร้อมให้เช่า พร้อมคิวเช่าถัดไป โดยการพักหรือลบประกาศไม่ลบ Booking และรายได้เก่า
- Rental Requests แบ่งเป็น “ต้องทำตอนนี้”, “กำลังดำเนินการ” และ “ประวัติ” พร้อม Next Action เพียงรายการเดียวต่อ Booking เพื่อให้รับ–ส่ง ตรวจสภาพ และทำความสะอาดต่อได้ตามลำดับ
- Pending Earnings และ Available Earnings คำนวณจาก Mock Escrow ledger และทุกรายการผูกกลับไปยัง Booking เดิม
- หนึ่งประกาศมีหลายไซซ์ แต่ละไซซ์มีราคาเช่าต่อวัน ขนาดวัด และสถานะเปิดให้เช่าแยกกัน
- จำนวนวันเช่านับรวมวันรับและวันคืน เช่น 11–13 กันยายนเท่ากับ 3 วัน
- รายการเช่าหลายร้านใช้ช่วงวันเดียวกัน จำนวนวันนับรวมวันรับและวันคืน และสร้าง Booking แยกผู้ให้เช่า
- Checkout ตรวจสต็อกและวันชนของทุกชิ้นใน IndexedDB transaction เดียว ถ้ารายการใดไม่ว่างจะไม่สร้าง Booking บางส่วน
- Booking เก็บ snapshot ชุด ผู้เช่า ผู้ให้เช่า ไซซ์ วันรับ วันคืน ราคา สถานะ Tracking สองขา และ Mock Payment/Escrow
- หุ่นใช้ฐาน Human Base Meshes ของ Blender และแสดงผลด้วย Three.js ที่รวมไว้ใน repository จึงไม่พึ่ง CDN
- Fit Summary ใช้กฎจากขนาดวัด แสดง Tight, Good, Slightly Loose, Loose, Short, Long หรือยังประเมินไม่ได้
- สัดส่วนหุ่นชายและหญิงบันทึกแยกกัน ขนาดเสื้อผ้าและการเลื่อนตำแหน่งเป็นข้อมูลคนละส่วนกับสัดส่วนหุ่น
- แต่ละตำแหน่งใส่ได้หนึ่งชิ้น: เสื้อ กางเกง วิก คอ เอว ใบหน้า และผม การเลือกชิ้นใหม่แทนที่เฉพาะตำแหน่งเดียวกัน
- Try-on แสดงเฉพาะโมเดล 3D ที่รองรับ สินค้าที่ไม่มีโมเดลยังลงให้เช่าและเลือกไซซ์ได้ แต่ไม่สร้างหุ่นหรือเสื้อผ้า 2D มาทดแทน
- ผู้ขายต้องระบุรูปตำหนิและคำอธิบายเมื่อเลือกสภาพ “มีตำหนิ”

## ทดสอบ

```bash
npm test
node --check app.js
node --check cosplay-domain.js
node --check cosplay-seller.js
node --check mannequin.js
node --check studio-renderer.js
node --check studio-ui.js
```

ชุดทดสอบอัตโนมัติครอบคลุมขอบเขต fit การตรวจสัดส่วน สิทธิ์บัญชี การคิดวันเช่าแบบ inclusive การกันวันชน การเก็บ snapshot การยืนยันโดยผู้ให้เช่า การลงชุดให้เช่า และการคงข้อมูลเดิม

## ข้อจำกัดของ MVP

- ไม่มี backend, การชำระเงินจริง, ขนส่งจริง, chat, review, ยืนยันตัวตน หรือแจ้งเตือนภายนอก Tracking และยอดเงินทั้งหมดเป็นข้อมูลจำลอง
- ข้อมูลอยู่ในเบราว์เซอร์และเครื่องเดียว อาจหายเมื่อล้างข้อมูลเว็บไซต์
- Virtual preview เป็นโมเดล 3D ที่สร้างโดยประมาณจากภาพอ้างอิง ไม่ใช่ photogrammetry, cloth simulation หรือการรับประกันความพอดี
- ภาพทั้ง 15 ภาพเป็นตัวอย่างจาก Wikimedia Commons และไม่ใช่ stock ของผู้ขายจริง ข้อจำกัดของภาพแต่ละใบอยู่ในเครดิตบนหน้ารายละเอียด
- ขั้นตอนลงชุดรับภาพสินค้าจริงสำหรับแกลเลอรี ไม่มีการอัปโหลด PNG เพื่อซ้อนเสื้อผ้าบนหุ่น 2D
- ผู้ช่วยคำบรรยายและราคาใช้กฎกับข้อมูลในระบบ และเปิดเผยจำนวนรายการเทียบเคียง
